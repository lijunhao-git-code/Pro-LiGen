# P1：最高QED选择与QED评价耦合的离线审计

先阅读 `结果说明与人工核查.md`。本轮用已保存的研究B候选比较首个合格、随机合格、最高QED，并检查候选整体分布与候选数量敏感性。

没有新增API调用、训练或对接，没有修改论文或推送GitHub。研究B原375个最终输出和1500条已有重放记录全部复现。

## 目录

- `inputs/`：原样复制的原始计划记录、候选、原参考分子、原重放记录及前一轮已核验的结构描述符；来源与哈希见protocol.json。
- `protocol.json`：本轮计算前固定的分析口径，明确事后探索身份、分母、随机抽取、统计单位和局限。
- `code/`：实际运行的分析、绘图、独立审计、报告及可移植运行入口。
- `results/`：原候选补全2250位置的审计网格、12000条选择重放、2250个随机抽取支持分布、任务均值、六个新增统计检验及验证回执。
- `figures/`：三张PNG和可编辑SVG，附4611条完整绘图坐标及源CSV哈希。
- `frozen_inputs_and_code.json`：计算前固定输入、协议与核心代码的指纹；后续加入的图表、报告及审计工具由最终file_manifest.json记录。
- `originals_before.json` / `results/originals_integrity.json`：论文与公开包文件未改动的前后核查。
- `file_manifest.json`：最终交付文件的SHA-256，排除自身与运行缓存。

## 运行入口

在本文件所在目录，用符合requirements.txt的Python3.10环境运行：

```text
python code/reproduce.py --output ../selection_audit_rerun
```

输出目录必须尚不存在。入口会核对固定输入与核心代码，复制必要文件到新目录，再依次运行分析、绘图、独立审计和报告。已通过真正的新目录完整重跑，14份数值数据、绘图坐标和报告文件逐字节一致，见results/fresh_rerun_verification.json。

若仅需核对交付数据与图片坐标：

```text
python code/audit.py
```

该命令仅更新独立审计回执。实际环境为Python3.10.7、NumPy1.23.5、pandas2.0.3、RDKit2026.03.4、Matplotlib3.7.2；没有安装新的Python环境，不需要GPU、PyTorch、API密钥或网络。

## 关键口径

主要随机结果是每条原轨迹合格且不同的canonical结构的均匀选择精确期望，避免任意选择随机种子。另提供按提案位置抽取的期望及基于42的固定种子具体抽样。期望行的selected_canonical为空，因为它代表分布的平均表现，不代表生成了一个平均分子。

技术失败的一条T轨迹没有保留的完成尝试候选，六个计划位置记为missing，留在2250位置分母中；不把这六个位置称为模型实际提案。无效、重复、非合格记录均保留。

前1至6个位置的曲线是既有候选的检查数量敏感性；第二轮已用过完整第一轮反馈，不能当成API费用或独立缩小生成请求数的实验。原研究C的反馈因果分析身份没有改变。本轮随机输出选择也不能替代尚未开展的随机输入范例R组。
